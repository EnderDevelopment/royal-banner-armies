# Minecraft Army Recruitment Plugin

Royal Banner Armies is a Minecraft Paper plugin for recruiting and managing medieval faction units through a Royal Banner item and an in-game recruitment menu. It provides 20 unit choices across the Humans, Elves, Dwarves, and Orcs factions, with faction tags, configurable unit health and attack damage, basic ally recognition, nearby targeting, and owner following.

## Install

1. Use a Paper server running Minecraft 1.21.11 with Java 21.
2. Place the compiled `plugin.jar` file in the server’s `plugins` folder.
3. Restart the server.

## Use

1. Run `/army banner` to receive a Royal Banner, or run `/army` to open the recruitment menu.
2. Use the Royal Banner to open the menu.
3. Select a unit to recruit it near your character. Recruited units follow their owner when idle and target nearby living entities marked as belonging to another faction.
